## The Moat (M2)

**Why this won't get copied in 6 months.**

- **Data Flywheel Score:** 15 / 20 (Correction: 4/5 · Preference: 3/5 · Domain Context: 4/5 · Network: 4/5)
- **Weakest Loop:** Preference (3/5) — local utility searches start largely stateless before caching resident context, creating an opening for personalized neighborhood feeds.
- **Top Encroachment Threat:** Vertical Competitor (Nextdoor launching an address-verified N21 micro-subnet within 6–12 months; ~40% value at risk) & Platform Encroachment (Apple Maps/Wallet local curation within 12–18 months; ~30% value at risk).
- **Encroachment Defense:** Deepen the Preference loop with native N21 errand itineraries and formal complaint generators while maintaining zero-bloat civic utility (`SEARCH`, `REPORT`, `CONNECT`) free from ad-driven social noise.
- **Vendor Portability:** Partial (3.5/5 Portability Score — state and vector anchors live in portable Supabase PostgreSQL/pgvector, requiring ~48 hours to abstract direct edge SDK calls behind a unified model gateway).

## The Margin (M3)

**Will this make money or bleed it?**

- **Gross Margin (current):** ~82% (pre-scale baseline on free/tier-cached edge infrastructure)
- **Gross Margin (AI-adjusted):** ~76% (accounting for LLM-as-a-judge CI/CD evals, Supabase vector sync, and 80/20 cascaded inference)
- **Pricing Model:** **hybrid** (Merchant flat-fee directory/sponsorship tiers + outcome-based municipal routing/telemetry contracts)
- **Pricing Today → Tomorrow:** Free beta → Hybrid (Access flat-fee for local N21 merchants + Outcome-based intent routing / Enfield Council civic telemetry contracts)
- **Total AI COGS / unit:** ~£0.004 per blended resident session (with semantic caching enabled for repeat local queries)
- **Cascading Strategy:** Triage: Lightweight open-weights/small edge model (80% volume) for initial intent classification, translation, and emergency intercept screening; Frontier: High-capability reasoning model (20% volume) for multi-step action execution, local itinerary synthesis, and structured council report payloads.
- **Net Margin Shift:** +18% margin preservation via 80/20 tier routing and 40% semantic cache hit rate on repeat N21 civic/merchant queries vs. uncached frontier-only routing.
- **Break-even at:** ~85 paying N21 merchant partners (at £25/mo) or 1 local municipal telemetry pilot covering core Vercel/Supabase/API baseline (~£350/mo hidden/infra spend + baseline ops).

## The Contract (M4)

**Why users will trust a probabilistic system.**

- **Reliability Target:** >96% intent routing accuracy across `SEARCH`, `REPORT`, and `CONNECT`, with 100% recall on 999/111 emergency hard-stops and <2% hallucination rate on local civic/merchant facts.
- **Golden Dataset:** 225-row curated N21 test suite covering Winchmore Hill street names, Enfield Council waste/highway rules, local slang, multi-lingual inputs, and adversarial prompt injections.
- **Confidence UX:** **tiered confidence** + **human-in-loop trigger** (high-confidence queries execute immediately; medium confidence surfaces structured disambiguation cards; low confidence triggers clarifying prompts).
- **HITL Architecture:** Mandatory human-in-the-loop review and manual click-to-submit for all municipal council reports (preventing automated API spam and ensuring human consideration), plus weekly human review of flagged edge-case logs.
- **Failure Mode Coverage:** *Partner-identified broken loop:* Stale Supabase vector anchors drifting out of sync with live Enfield Council and Google Places updates during a 3-month code freeze. *Fix:* Automated Supabase database webhooks and edge triggers that re-index vector anchors whenever upstream API payloads change, validated in CI/CD.

→ Details: [`04-the-contract/`](04-the-contract/)

## The Guardrails (M5)

**What breaks when this scales, and what compounds.**

- **Compounding System:** Automated CI/CD evaluation harness using LLM-as-a-judge and synthetic test variant generation against the 225-row Golden Dataset—allowing routing accuracy to self-heal and survive a 3-month engineering freeze without degradation.
- **Governance Posture:** Limited-risk generative utility with strict operational boundaries, zero autonomous external write-access, and human-governed civic submissions.
- **Autonomy Boundaries:** Autonomous execution permitted for local `SEARCH`, `CONNECT`, factual retrieval, and drafting pre-filled report payloads. **Hard-stops:** Zero autonomy on 999/111 emergency descriptors (instant emergency redirect screen) and strict prohibition on automated direct council ticket submissions.
- **Escalation Triggers:** Emergency/crisis keywords (999/111), adversarial prompt injection or data exfiltration flags, and edge confidence scores falling below routing thresholds.
- **Audit Cadence:** Real-time (CI/CD PR eval gates), Daily (Vercel edge & Supabase telemetry logs), Weekly (human review of low-confidence edge cases & drift anomalies), Monthly/Quarterly (tier-routing cost & API rate-limit audits).
- **Shadow AI Audit (user-side):** Audited 14 tools down to 6 core stack components (~£350/mo hidden spend). Surfaced 5 resident workarounds—prioritizing **Build** for native council complaint formalizers and Green Lanes errand itineraries, **Partner** for N21 tradesman pricing benchmarks, and **Ignore** for niche group polls and already-covered translations.
- **Agent Boundaries:** Router Agent (Edge/Small tier) classifies intent and screens safety/emergencies; Synthesis Agent (Frontier tier) merges live API JSON with Supabase vector anchors. Neither agent can execute raw SQL, alter schemas, or auto-submit council tickets.
- **Regulatory Exposure:** **Limited Risk** under EU AI Act alignment (requires AI transparency notices and anti-hallucination documentation); full compliance with UK GDPR & Data Protection Act 2018 for resident PII and chat telemetry.

## The Pitch (M6)

**How you get this funded, shipped, and adopted.**

- **Horizon 1 (Now — 0 to 4 Weeks):** Ship core N21 utility router (`SEARCH`, `REPORT`, `CONNECT`), 225-row Golden Dataset CI/CD harness, 999/111 emergency hard-stops, and pre-filled Enfield Council report drafts to establish baseline resident trust.
- **Horizon 2 (Next — 1 to 3 Months):** Validate and ship high-signal Shadow AI features—native "Formalize Complaint" tone selector and Green Lanes errand planner—while enforcing kill criteria on inference margins and webhook sync reliability.
- **Horizon 3 (Bet — 3 to 6 Months):** Expand the hyper-local playbook to adjacent North London postcodes (N14 Southgate, N13 Palmers Green) and pilot municipal civic telemetry dashboards and verified local tradesman networks.
- **Board Narrative:** **The case:** WiHi turns fragmented hyper-local friction in N21 into a defensible, self-healing utility moat that generic cloud wrappers can't replicate. **The model:** 80/20 tiered edge routing and semantic caching protect ~76% AI-adjusted gross margins while merchant subscriptions and civic telemetry drive break-even at ~85 local merchants. **The risks:** Hard-coded 999/111 circuit breakers, human-gated council reporting, and automated webhook re-indexing eliminate liability and silent drift.
- **Ask:** £75k pre-seed / angel allocation (or 6-month runway milestone unlock) to fund N21 merchant onboarding, model gateway abstraction, and Enfield Council pilot integration.

### M1 Baseline vs. Now

- **Key Strategic Change:** Shifted from a static local directory and chat wrapper (M1) to a **self-healing, human-governed civic orchestration engine (M6)**—replacing risky automated ticket submission with human-verified pre-fills, cutting 8 fringe tools to protect margins, and turning user Shadow AI workarounds (complaint formalizing & errand planning) into our primary H2 product roadmap.
